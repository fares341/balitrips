التجاوب والاتجاه

مقاسات مرجعية 390 · 768 · 1440، ونقاط توقف عند 640 / 768 / 1024 / 1100 / 1200. كل المسافات بخصائص منطقية (inset-inline, padding-inline, margin-inline) فتنعكس تلقائيًا بين RTL وLTR. الأيقونات الاتجاهية (الأسهم) تُعكس بـ .flip. الأرقام ورقم الجوال والبريد dir="ltr". يحترم prefers-reduced-motion كل الحركات.
