# Bali Trips — حزمة UI/UX للمبرمج (v3 · أكتوبر ٢٠٢٦)

هذه الحزمة هي المرجع البصري والوظيفي الكامل لمنصة Bali Trips: الموقع العام بالعربية والإنجليزية، ولوحة التحكم، وكل الحالات.

## محتويات الحزمة

| المجلد | ما فيه |
|---|---|
| `PROMPT.md` | برومت جاهز لتسليم الحزمة لأي ذكاء اصطناعي: بناء الموقع الحقيقي (أ)، أو تطبيق نفس الشكل على ملف آخر (ب). |
| `prototype/` | النموذج التفاعلي كاملًا (HTML/CSS/JS). الروابط والتسعير والحجز والخريطة كلها تعمل. |
| `source/` | ملفات المصدر للنموذج: أجزاء الصفحات في `src/`، و`build.py` الذي يجمعها في `prototype/`، وسكربتات الفحص وتصدير الشاشات. |
| `screens/ar-desktop-1440/` | ٥٥ شاشة عربية للديسكتوب (صفحة كاملة). |
| `screens/ar-mobile-390/` | نفس الـ٥٥ شاشة للجوال (بدقة @2x). |
| `screens/ar-tablet-768/` | الشاشات الأساسية على التابلت. |
| `screens/en-desktop-1440/` و`screens/en-mobile-390/` | الشاشات الأساسية بالإنجليزية (LTR). |

أسماء الشاشات مرقمة بنفس ترتيب خريطة الموقع (`01-home`، `03-map`، `06-activity-detail`، `30-admin-overview`...).

## تشغيل النموذج

المتصفح يمنع بعض الملفات عند فتحها مباشرة، لذلك شغّله من خادم محلي:

```
cd prototype
python3 -m http.server 8080
# ثم افتح http://localhost:8080/index.html
```

- `index.html`: صفحة المشروع، وفيها التحليل والـSitemap ومسارات المستخدم وكل الروابط.
- `home.html`: الموقع العام. اللغة تتبدل من الهيدر (عربي RTL / English LTR).
- `admin.html`: لوحة التحكم. فيها زر EN/ع، وقائمة لمحاكاة الأدوار (مدير النظام، محرر المحتوى، مسؤول الحجوزات).

## الصفحات المرجعية للمبرمج داخل النموذج

- `handoff.html`: البنية المقترحة، والمسارات (routes)، ونموذج البيانات، ومعادلات التسعير، وقواعد الإضافات، وحالات الحجز والدفع، ومستويات تنفيذ الخريطة، ومواصفات الحركة، والوصول والأداء، وأحداث التحليلات.
- `design-system.html`: الألوان، والتباين، والخطوط، والمسافات، والحواف، والظلال، وكل المكونات بحالاتها.
- `states.html`: حالات التحميل، والأخطاء، والحقول، والفراغ، وانقطاع الاتصال، وحالات الحجز.

## قواعد يجب الالتزام بها في التنفيذ

1. **كل زر وكل كارت يفتح صفحة مستقلة.** الاستثناء الوحيد هو تأكيدات الإجراءات، مثل اقتراح إضافة السائق قبل الدفع وتأكيد الحذف.
2. **التسعير يُحسب لحظيًا:** الباقة (للفرد أو للمجموعة) + الإضافات (للفرد أو للحجز أو حسب الكمية) + السائق (سعر اليوم × عدد الأيام). المعادلة الكاملة في `handoff.html`.
3. **قواعد الإضافات:**
   - الإضافة المشمولة في الباقة تظهر مقفلة ولا تُحسب.
   - الإضافة غير المتاحة مع الباقة المختارة تظهر معطّلة مع ذكر السبب.
   - الإضافة المشروطة لا تُختار قبل شرطها.
4. **منع الحجز قبل اكتمال البيانات:** التاريخ، والوقت (للأنشطة)، وعدد الأفراد. تظهر رسالة خطأ تحت كل حقل ناقص.
5. **حالة «مؤكد» تظهر فقط بعد تأكيد مزود الخدمة**، وليس لمجرد نجاح الدفع.
6. **إعادة محاولة الدفع تستخدم نفس رقم الطلب**، فلا يتكرر الطلب.
7. **الخريطة:**
   - تُبنى بـ MapLibre مع طبقة قمر صناعي.
   - الأماكن خارج المنطقة المجانية تُرسل من الخادم بدون تفاصيل حتى يشتري المستخدم الخريطة. الإخفاء في الواجهة وحده لا يكفي.
   - 3D والجولة الافتراضية مراحل لاحقة، وتفاصيل المستويات في `handoff.html`.
8. **CSS بخصائص منطقية فقط** (`inset-inline`، `padding-inline`...) حتى تنعكس الصفحات تلقائيًا بين RTL وLTR. الأرقام والأسعار والهواتف تُكتب `dir="ltr"`.
9. **الزر البرتقالي نصه أخضر داكن `#13301A`، وليس أبيض**، لأن الأبيض على البرتقالي تباينه ٢:١ فقط.
10. **لا أرقام ولا تقييمات غير حقيقية في النسخة الفعلية.**

## بيانات تجريبية يجب استبدالها

- **الأسعار:** بعضها منقول من الموقع الحالي ومعلَّم بـ `siteprice: true` في `data.js`، والباقي تجريبي.
- **التقييمات، وأسماء بعض المطاعم** (المكتوب بجانبها «نموذج»)، **وبيانات التواصل.**
- **صور الأنشطة والمطاعم الفعلية:** تأتي من المزودين، وحقوق استخدامها مطلوبة.
