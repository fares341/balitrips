# سيناريوهات الاختبار قبل الإطلاق — Bali Trips

مرجع كل سيناريو: قسم "الوثيقة التفصيلية" بين قوسين. الهدف: تجربة كل ما طلبته
الوثيقة على نسخة **staging** بمفاتيح test قبل فتح الحجز للجمهور.

**طريقة الاستخدام:**
- نفّذ الأقسام بالترتيب: كل قسم يعتمد على حسابات وبيانات القسم الذي قبله.
- علّم كل سيناريو: ✅ نجح / ❌ فشل (مع لقطة شاشة ورقم الطلب أو البريد) / ⏭️ مؤجل.
- أي ❌ في الأقسام المعلّمة بـ 🔴 يمنع الإطلاق.

## 0) التجهيز

### 0.1 الاختبارات الآلية (على جهازك أولاً)

```bash
pnpm install
pnpm db:migrate                 # حتى 0010_prelaunch_review
pnpm format:check && pnpm typecheck && pnpm lint
pnpm test                       # اختبارات الوحدة
pnpm vitest run --config vitest.integration.config.mts           # تحتاج Postgres محلياً (انظر docs/local-setup.md)
pnpm test:e2e                   # Playwright: تسجيل، دخول بالجوال، الخريطة المقفلة…
```

> كل الأوامر يجب أن تنجح بلا أخطاء قبل المتابعة. أرسل أي خطأ كما هو.

### 0.2 بيئة staging

| الإعداد | القيمة |
|---|---|
| `LIVE_MODE` | `true` (كالإنتاج تماماً) |
| `PAYMENT_PROVIDER` | `stripe` بمفاتيح `sk_test_…` و webhook حقيقي من Stripe Dashboard |
| `ALLOW_BOOKINGS` | `true` |
| `EMAIL_TRANSPORT` | `resend` بنطاق موثّق (SPF/DKIM) — لا `console` |
| `GEO_COUNTRY_HEADER` / `GEO_CITY_HEADER` | `cf-ipcountry` / `cf-ipcity` إن كان Cloudflare مفعّلاً |
| واتساب | اختياري في staging؛ إن فُعّل: رقم اختبار من Meta |
