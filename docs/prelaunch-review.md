# ما قبل الإطلاق — النواقص المكمّلة ومراجعة الكود الكاملة

## التشغيل

```bash
pnpm install
pnpm db:migrate          # 0010_prelaunch_review: فهرسان لعدّ "الأكثر حفظاً"
pnpm format:check && pnpm typecheck && pnpm lint && pnpm test
```

متغيرات جديدة:
- `GEO_CITY_HEADER`: افتراضياً `cf-ipcity`.
- `.env.production.example` اكتمل. أهمها `ALLOW_BOOKINGS`، وقيم واتساب، وتسجيل الدخول بـ Google/Apple.
- `deploy/cloud-init.yaml` صار فيه `ADMIN_BASE_PATH` لـ Caddy.

> ما تمّ التحقق منه هنا: سلسلة الهجرات 0000→0010 على قاعدة جديدة، وفحص الصياغة والأسماء
> غير المعرّفة والاستيرادات لكل `src`، وتطابق مفاتيح الترجمة الثلاثة (997)، وPrettier، وست
> مراجعات مستقلة.
>
> لم يُشغَّل `typecheck` ولا الاختبارات، لأن البيئة بلا npm.

## 2) ما أصلحته المراجعة

### الدفع والطلبات

- **باقة/فئة "للفرد" مجاناً:** إرسال `guests: 0` كان يسعّر السطر بصفر. السلة و`buildQuote` يرفضانه الآن.
- **ضغطتا "ادفع" متزامنتان:** كانتا تنشئان طلبين وتحجزان السعة مرتين. المفتاح يُحجز الآن داخل معاملة الطلب.
- **جلستا Stripe لنفس السلة:** الرجوع ثم الدفع مجدداً كان يترك الجلسة الأولى قابلة للدفع.
  - الجديدة تُغلق السابقة، ولا يُلغى الطلب القديم إلا بعد تأكيد Stripe أنه أُغلق بلا دفع.
- **فشل إنشاء جلسة الدفع:** الطلب يُلغى وتعود السعة، وإعادة المحاولة تنشئ طلباً جديداً بدل التحويل لطلب ميت.
- **الاسترداد:**
  - يختار الدفعة الصحيحة، وطلب مدفوع بتحويل بنكي يُسترد بلا استدعاء Stripe.
  - استرداد سطر يسحب ما منحه ذلك السطر فقط.
- **دفعة مكررة** (تحويل بنكي ثم بطاقة):
  - تظهر "duplicate" في Payments، وتُسترد بزر دون المساس بالطلب.
  - الـ webhook لا يعيد إفراغ السلة ولا إشعار "تم الدفع".
- **تجديد مؤجَّل:** كان يمنح الوصول قبل موعده، فيتجاوز مقاعد العائلة. الآن لا يمنح شيئاً قبل بدايته.

### الدخول والحماية

- **الـ IP المحظور:** كان يواصل تخمين كلمات المرور، ويكشف له الرد المختلف أن الكلمة صحيحة. يُرفض الآن قبل أي فحص.
- **حظر تلقائي خاطئ:** مستخدم عادي غيّر هاتفه وضغط "دخول" عدة مرات كان يُحظر 24 ساعة.
  - القاعدة الآن: 6 أجهزة **مختلفة** في أسبوع.
  - والمحاولات المرفوضة تنبيه فقط.
- **فك الحظر ذاتياً:** المستخدم كان يستطيع "إزالة" جهاز حظرته الإدارة فيعود يدخل به.
- **الاستيلاء المسبق على الحساب:** مهاجم يسجّل ببريد الضحية قبلها. عند دخول الضحية بـ Google تُحذف كلمة مروره.
- **رابط تأكيد البريد:** كان يسجّل الدخول من جهاز آخر فيستهلك خانة جهاز.
- **مدخلات ومعدّلات:**
  - اسم طويل كان يعطي خطأ 500.
  - تسجيل الصفحات المزارة صار بحد.
- **2FA للإدارة:** بلا حد محاولات سابقاً. الآن 5 محاولات ثم قفل 15 دقيقة وخروج الجلسة، والمحاولة تُحجز قبل الفحص فلا يتجاوزها التوازي.

### الخريطة وPDF

- **الخريطة ثلاثية الأبعاد** (ما يراه أغلب الزوار):
  - كانت تتجاهل `?place=` ولا تعرض شريط الشراء أبداً.
  - عند فشل WebGL كانت شاشة تحميل لا تنتهي، والآن تتحول للخريطة المسطحة.
- **حد التحميل:** كان يُتجاوز بطلبات متوازية. صار حجزاً ذرّياً، والتسليم الفاشل لا يُحتسب.
- **العارض:** حد 20 فتحاً يومياً لكل جدول، وكل فتح مسجّل. انظر الحدود المعروفة في checklist.md.
- **"جداولي":**
  - السطر الملغى لم يعد يظهر بأزرار تعطي 404.
  - الـ PDF المرفوع يدوياً يظهر "جاهزاً".
- **البحث:** صار يقدّم صوراً مصغّرة بدل الأصل (1–1.6MB)، مع فهارس للعدّ.

### لوحة التحكم

- **تصدير المدفوعات:** كان متاحاً للموظفين ويحمل بريد كل العملاء بلا تسجيل.
- **ربط طلب مخصص:** كان يمكن ربطه بأي حساب، فتظهر خطة رحلة شخص لآخر. الآن بنفس البريد فقط، ومرة واحدة.
- **إصلاحات أخرى:**
  - تعديل فئة نشاط صار مقيّداً بنشاطها.
  - صلاحية منتهية لا تمنع منحاً جديداً.
  - "تسجيل دفع بنكي" لا يُظهر خطأً بعد نجاحه.
  - حد PDF الجدول صار 24MB ليطابق حد الخادم.

### الإنتاج

- **صفحات الحساب والفواتير و/plans:** كانت تُرسل بـ `Cache-Control: public`. خلف Cloudflare تُخزَّن صفحة عميل وتُعرض لغيره. صارت `private, no-store`.
- **`.env.production.example`:** كان ينقصه `ALLOW_BOOKINGS`، فيقفل الحجز كله عند الإطلاق، وقيم واتساب وتنبيهات الفريق.
