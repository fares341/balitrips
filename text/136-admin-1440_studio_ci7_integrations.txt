أنواع الاتصال
النوع	المعنى
يدوي
جاهز للاستخدام
	يحجز الفريق مع المورد بالهاتف أو واتساب أو البريد كما هو الحال الآن، ويسجّل الاتصال كل تأكيد.
جدول بيانات (CSV)
جاهز للاستخدام
	يرسل المورد جدولاً بالمنتجات والتكاليف والتوفر. ترفعه وتراجع المعاينة ثم تطبّقه.
واجهة REST
يتطلب مطوّرًا لكل مورد
	نظام المورد يجيب على الطلبات عبر الإنترنت.
واجهة GraphQL
يتطلب مطوّرًا لكل مورد
	مثل واجهة REST بصيغة طلبات مختلفة.
إشعارات تلقائية (Webhook)
يتطلب مطوّرًا لكل مورد
	نظام المورد يرسل لنا التحديثات لحظة حدوثها.
دخول OAuth 2
يتطلب مطوّرًا لكل مورد
	ندخل إلى نظام المورد نيابة عنا برمز ينتهي بعد مدة.
مفتاح API
يتطلب مطوّرًا لكل مورد
	نستخدم مفتاحاً أعطانا إياه المورد للوصول إلى نظامه.
مزامنة مجدولة
يتطلب مطوّرًا لكل مورد
	نجلب تحديثات المورد في أوقات محددة.
